## 1. 제품 정의

**사용자**: 보험 청구자 · 사고자 **본인** (전문가 아님)

**흐름**

```
본인의 사고 · 질병 · 담보에 대한 질문
        ↓
보상 진단 (실손 · 정액 담보 · 후유장해 · 특별 보상)
        ↓
연계 손해사정사에게 카톡 · 전화 상담 전달
        ↓
수임
```

**핵심 메시지** — "이것도 되고 저것도 되고, 이만큼이나 나온다"
실비 하나만 청구하고 끝내는 사용자에게 **놓치고 있던 담보를 전부 펼쳐 보여주는 것**이 제품의 전부입니다.

**참조 디자인**: KOICD 담보확인 페이지(`koicd.kr/insu/insu.do`) — 검색 → 코드 확인 카드 → 청구 가능 담보 그리드 → 면책 문구

## 3. 디자인 언어 (화면 02가 기준)

### 4카테고리 고정 프레임

사고든 질병이든 **답은 항상 이 4개**입니다. 내용만 케이스별로 교체됩니다.

| # | 카테고리 | 설명 |
|---|---|---|
| 1 | 실손 의료비 | 병원에 낸 돈을 돌려받음. **가입년도(1~4세대) 수집 배너 내장** |
| 2 | 정액 담보 | 진단 · 수술 · 입원마다 따로. 가장 많이 놓치는 부분 |
| 3 | 후유장해 | 금액이 가장 큼. **상담 CTA 배치 지점** |
| 4 | 특별 보상 | 배상책임 · 단체보험 등 내 보험이 아닌 곳 |

골절 케이스의 담보 10종은 **데이터의 한 사례**입니다. 암이면 암진단비 · 항암치료비, 뇌질환이면 뇌졸중진단비로 교체됩니다.

### 담보 카드 (`Coverage Item`)

3톤 상태 pill:

| 상태 | 배경 / 보더 | pill | 용례 |
|---|---|---|---|
| `청구 가능` | `$ok-soft` / `$ok-line` | `$ok` + 흰 글씨 | 해당되는 담보 |
| `조건부` | `$warn-soft` / `$warn-line` | `$warn` + 흰 글씨 | 조건 충족 시 |
| `해당 없음` | `$surface` / `$line` | `$surface-inset` + `$ink-4` | **해당 안 되는 것도 노출** |

**해당 없음을 숨기지 않습니다.** "5대 골절 진단비 — 두개골·척추체·고관절만 해당, 무릎은 제외"처럼 왜 안 되는지 적습니다. 안 되는 걸 말해주는 쪽이 되는 것도 믿게 만듭니다.

### 레이아웃

- 중앙 컬럼 1080 (02) / 760 (01) / 720 (03)
- 담보 그리드 3열, 카드 간 14 · 카테고리 간 28
- 카테고리 헤더: 번호칩 + 제목 + 한 줄 요약 + 우측 카운트 배지
- 면책 문구: 주황(`#E8622D` / `#8A3410`), 결과 카드 최하단 고정
- 다크 서피스(`$sidebar`): 최종 CTA에만 사용

### 상담 CTA 배치 (3곳)

| 위치 | 문구 | 의도 |
|---|---|---|
| 상단 탑바 | `카톡 상담` | 언제든 이탈 없이 |
| 후유장해 섹션 | `내 장해율이 얼마나 나올지 궁금하신가요?` | 금액이 가장 크고 혼자 판단 불가능한 지점 |
| 하단 최종 CTA | `11가지를 전부 청구하시겠어요?` | 전체 확인 후 전환 |

## 4. 금액 표기 정책 (유지)

B2C 대상이므로 단정형 금액 제시는 표시광고법 · 보험업법 리스크가 있습니다.

- **놀라움의 축은 금액이 아니라 담보 개수** — `11개 해당` / `4가지 보상 종류`
- 금액은 항상 **범위** (`약 300만 ~ 1,200만원`), 정액 담보만 단일 금액 + `정액 · 약관 확정`
- 면책 문구 필수 노출 — 숨기거나 툴팁 처리 금지
- 단정형 표현(`받으실 수 있습니다` 확정형) 금지 → `청구 가능` / `가능성` 표기

- 금액은 실제 값을 그대로 노출 — 클라이언트에서 재계산하지 않고 서버 산정값을 그대로 렌더링
- `평가 대기` 항목은 합계에 포함하지 않음 — 확정 항목과 미확정 항목의 합산 표기를 분리
- 면책 · 감액은 색상만으로 구분하지 않음 — 아이콘 + "면책"/"감액" 텍스트 라벨을 항상 함께 표기

## 5. 폐기된 설계 (이력)

기획이 여러 차례 바뀌며 아래 방향은 모두 폐기되었습니다. 되돌아올 경우 git 이력에서 복구할 수 있습니다.

| 폐기 | 내용 |
|---|---|
| **손해사정사 워크스페이스** | 사이드바 · 사건 관리 · 리서치 리포트 · 전문가 피드백 · 입증 서류 · 후유장해 트래커. 사용자가 전문가라는 전제였음 |
| **3단계 동적 문진** | 사고 경위 → 진단·치료 → 가입 연도. 검색창 한 줄 입력으로 대체 |
| **청구 주체별 결과 축** | 지자체 / 공단 / 보험사로 나눈 구조. **보장 유형별** 4카테고리로 대체 |
| **손해사정사 영업 판단 바** | 예상 총 보상 · 고객 미인지 항목 · 수임 판단 · 상담 포인트 |
| **모바일 390 버전** | 데스크톱 우선으로 정리 |

구 `SPEC-funnel-dashboard.md`는 위 폐기분(대상 화면 표 · 화면별 구조 · 신규 컴포넌트 4종)만 담고 있어 전체 삭제했습니다. 그 안에 있던 금액 · 면책 표기 규칙만 §4로 옮겨 남겼습니다.
