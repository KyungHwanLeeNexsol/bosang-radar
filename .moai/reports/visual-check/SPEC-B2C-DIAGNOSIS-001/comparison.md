# 시각 정합성 비교 — SPEC-B2C-DIAGNOSIS-001 (D2 6차 재검증, 2026-09-20)

**이 문서는 이전 버전("D2 5차 재검증")을 완전히 대체한다.** 6차 외부
재검토는 5차의 textarea 전환·모바일 카드 2단 구조·모바일 배경색·01-A2
모달 높이 방향 수정은 유효하다고 확인했지만, 다음 세 가지 방법론
결함을 지적했다: (1) 최신 코드로 캡처한 스크린샷이 한 장도 커밋되지
않아 좌표값을 재현 검증할 수 없었다, (2) 디자인은 ink-only 픽셀
세그먼트, 구현은 DOM line-height box로 서로 다른 방식을 비교해
Δ값이 신뢰할 수 없었다(특히 01-B 제목 12px 판정), (3) M01 푸터 목표를
"1110 프레임 이내"로 완화한 것은 디자인의 실제 좌표(y≈1054)를
반영하지 않은 것이다.

이 문서는 세 가지를 모두 해결한다: 10개 화면을 최신 코드로 재캡처해
커밋하고, 디자인·구현 이미지를 동일 크기로 맞춰 동일 ink-pixel
세그먼트 알고리즘으로 직접 비교하며, overlay/diff 이미지를 생성해
커밋한다.

## 측정 방법론 (6차, 동일 좌표계 비교로 전면 교체)

1. **동일 좌표계 비교(신규, 핵심 수정)**: `design/exports/*.png`(2배
   해상도)를 Playwright `<canvas>`에 50% 축소로 그리고, 구현은
   `pnpm build && pnpm start` 프로덕션 서버에서 디자인과 **정확히 같은
   1배 viewport 크기**로 캡처한 뒤, **동일한 ink-pixel 세그먼트
   함수**(배경색 임계값 기반 행 스캔 + quiet-gap 블록 분리)를 두
   이미지 모두에 적용해 top/height/width를 직접 뺐다. DOM
   `getBoundingClientRect()`는 세그먼트가 교란되는 반투명 오버레이
   화면(01-A2/M01-A2)에서만 보조 자료로 사용했다.
2. **모달/시트 전용 크롭 세그먼트**: 01-A2/M01-A2는 반투명 backdrop
   뒤로 배경 페이지가 비쳐 일반 세그먼트가 내부를 하나의 큰 블록으로
   뭉갰다 — 먼저 밝기 임계값(RGB>235)으로 모달/시트의 불투명 흰 박스
   경계를 찾고, 그 영역만 크롭해 좌우 테두리(6px 인셋)와 상단 모서리
   그림자(16px 여유)를 제외한 뒤 내부 요소를 재세그먼트했다.
3. **overlay/diff 이미지 10쌍 생성 및 커밋**: 화면마다 (a) 50% 정규화
   디자인 PNG, (b) 최신 구현 캡처, (c) 구현 위에 디자인을 50%
   opacity로 겹친 overlay, (d) 픽셀 단위 절대차이를 빨간 강도로
   표시한 heatmap diff — 4종을 모두
   `.moai/reports/visual-check/SPEC-B2C-DIAGNOSIS-001/` 하위
   (`screenshots/`, `normalized-design/`, `overlays/`, `diffs/`)에
   커밋했다(§ Overlay/Diff 인덱스).
4. **`nextjs-portal` 부재 확인**: 10개 화면 전부 캡처 직전
   `page.locator("nextjs-portal").count()`가 0임을 확인했다(§ 캡처
   증거 참고).
5. **허용 오차**: Desktop 8px, Mobile 4px. 이 문서의 표는 이 기준으로
   PASS/FAIL을 명시하며, 초과 항목만 별도로 §허용 오차 초과 항목에
   모은다(단순 잔여 위험과 분리).
6. **`.pen` 미접근 잔여 위험은 유지**: 정확한 폰트 크기 등은 여전히
   추정값이다.

## 단순 잔여 위험 (허용 오차 초과가 아닌 것 — §완료 조건 대응의 "허용 오차 초과 항목"과 분리)

- **M01/M01-C 제목이 여전히 단일 행**: M01-B와 M01-A2는 이번 라운드에
  `max-w-[Npx]`로 2줄 줄바꿈을 성공시켰지만, M01/M01-C의 제목("이거,

  동일 처리를 적용하지 않았다 — 이번 라운드 지시사항에 명시적으로
  포함되지 않아 범위에서 제외했다(잔여 위험으로 기록).
- **M01-B 진행률 트랙의 정확한 디자인 px 값**: 트랙 자체가 배경과
  저대비라 ink 세그먼트로 측정할 수 없었다 — 디자인 이미지 육안
  확인으로 "상당히 긴 트랙"임을 확인하고 `w-24`(96px)→`w-[180px]`로
  확장했으나, `.pen` 원본 접근 없이는 정확한 목표 px를 알 수 없다.
- **01-B/C/D/E 제목 font-size 정확값**: `.pen` 미접근으로 여전히
  추정값(01-B: 26px, 01-C: 26px, 01-D/E: 21px).
- **badge 요소의 저대비 측정 신뢰도**: `bg-green-50` 배지가 옅은
  Mobile 배경(#f4f6f8)과 대비가 낮아 ink 세그먼트가 배지의 텍스트만
  감지하고 pill 배경 전체를 감지하지 못하는 경우가 있다(M01-B 배지
